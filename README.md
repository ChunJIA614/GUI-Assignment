# GUI Assignment

## Project Overview
This repository contains the GUI Assignment project, which is divided into two main sections:

1. **Admin Panel**: A set of HTML pages designed for administrative tasks such as managing products, staff, campaigns, and sales reports.
2. **Client Interface**: A user-facing interface for customers to browse products, manage their cart, and complete purchases.

## Folder Structure

### Admin/
- **HTML Files**: Contains pages for administrative tasks (e.g., `add-product.html`, `admin-login.html`, `product-list.html`).
- **CSS**: Contains the `styles.css` file for styling the admin panel.
- **Script**: Contains JavaScript files (`script.js`, `sidebarmenu.js`) for dynamic functionality.
- **Images**: Placeholder for admin-related images.

### Client/
- **HTML Files**: Contains pages for the client interface (e.g., `shop.html`, `cart.html`, `order-history.html`).
- **CSS**: Contains multiple CSS files for styling different pages (e.g., `style.css`, `login.css`).
- **Script**: Contains JavaScript files for client-side functionality.
- **Images**: Organized into subfolders (e.g., `about/`, `banner/`, `products/`).
- **Webfonts**: Placeholder for web fonts used in the client interface.

## Features

### Admin Panel
- Manage products, staff, and campaigns.
- View and edit sales reports.
- Administrative login and profile management.

### Client Interface
- Browse products and view details.
- Add products to the cart and proceed to checkout.
- View order history and manage user profiles.

## How to Use

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the `Admin/` or `Client/` folder in your browser to view the respective interfaces.

## Technologies Used
- **HTML**: For structuring the web pages.
- **CSS**: For styling the pages.
- **JavaScript**: For adding interactivity.
